# ntql-demo
This repository contains a runnable web page that uses the NTQL (NolaTask Query Language) as a demo.

## Getting Started
First, install Go. You can download it from [the official Go website](https://golang.org/dl/).

Next, clone this repository to your local machine:
```bash
git clone https://github.com/DeonteVanterpool/ntql-demo.git
cd ntql-demo
```

Then, run the Go program:
```bash
go run main.go
```

This will start a local web server. Open your web browser and navigate to `http://localhost:8080` to see the demo page, and interact with it.
